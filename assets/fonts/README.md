# Bundled fonts

Both are variable fonts licensed under the SIL Open Font License 1.1.

| File | Family | Source |
|---|---|---|
| `PlayfairDisplay-Variable.ttf` | Playfair Display | https://github.com/google/fonts/tree/main/ofl/playfairdisplay |
| `Geist-Variable.ttf` | Geist | https://github.com/google/fonts/tree/main/ofl/geist |

Variable fonts need an explicit `wght` variation. Use the `AppTypography.w400`
… `w900` constants alongside `fontWeight` when overriding a weight.
